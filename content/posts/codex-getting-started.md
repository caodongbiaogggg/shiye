第一次使用 Codex，最容易卡住的往往不是写代码，而是前面的几步：下载哪个版本、如何登录，以及打开之后应该先做什么。

这篇文章沿着一条完整的路线展开：**准备网络 → 安装客户端 → 注册与登录 → 按需完成手机号验证 → 打开练习文件夹 → 完成一个小任务。**

> 整理于 2026 年 9 月 10 日。配图展示的是教程录制时的界面。按钮名称、模型列表和可用功能可能随版本与账号变化。

## 01 · 先选一种使用方式

原教程介绍了桌面端、命令行、编辑器扩展和网页入口。第一次接触时，可以先从桌面端开始，熟悉项目、文件和任务之间的关系，再按需要尝试其他入口。

| 使用入口 | 适合从什么场景开始 |
| --- | --- |
| 桌面端 | 在图形界面里处理本地文件、查看任务和结果 |
| 命令行（CLI） | 已经习惯终端操作，希望在开发流程中使用 Codex |
| 编辑器扩展（IDE） | 希望在代码编辑器中阅读、修改和调试项目 |
| 网页与云端入口 | 希望在浏览器中使用，或开展云端任务 |

这些入口对应不同的工作环境，不能简单理解为“编辑器扩展只能改一个文件”或“网页只能聊天”。本文只展开桌面端的入门路线。官方入口说明见 [OpenAI 快速开始](https://learn.chatgpt.com/docs/quickstart)。

## 02 · VPN／代理：先准备网络环境

如果已经能够正常访问官方页面并使用客户端，可以直接进入安装步骤。如果当前网络无法连接，先检查网络，再配置自己使用的 VPN 或代理服务。

这里以 **Clash Verge Rev** 为例。它是管理代理配置的客户端，本身不附带可用的线路；还需要导入服务商提供的订阅，或者使用自己的代理配置。

### 第一步：安装 Clash Verge Rev

打开 [Clash Verge Rev 使用教程](https://www.clashverge.dev/guide/quickstart.html)，通过“下载与安装”选择适合系统和处理器的安装包。Windows 与 macOS 的安装包不能混用；Mac 还需要区分 Apple 芯片和 Intel 芯片。

下载后按安装程序提示完成安装，并打开应用。

### 第二步：准备并导入订阅

已有代理订阅的读者，直接使用自己的订阅即可。教程中列出的服务商示例是“狗狗加速”，其入口可在上面的 Clash Verge 文档中找到；套餐与可用线路以服务商当前页面为准。

1. 登录所用服务商的账户，找到订阅地址或“一键导入 Clash”入口。
2. 使用一键导入时，按浏览器提示打开 Clash Verge。
3. 手动导入时，在 Clash Verge 的“订阅”页面粘贴订阅地址，选择导入。
4. 等待订阅更新完成，选中刚导入的配置，确认代理页面出现节点列表。

订阅地址可能包含账户凭据，不要将完整地址放进公开文章、截图或 GitHub 仓库。

### 第三步：选择节点，开启代理

在代理页面选择可用节点和适合的规则模式，然后开启“系统代理”。如果浏览器能连接，但某个客户端或终端仍然无法连接，再对照教程检查是否需要 **TUN 模式**，并按客户端提示完成相关设置。

系统代理和 TUN 的区别在于接管网络请求的方式；并不是开启系统代理后，所有程序就一定经过代理。相关说明见 [Clash Verge 快速入门](https://www.clashverge.dev/guide/quickstart.html)。

### 第四步：测试连接

先在浏览器中打开官方页面，再打开客户端发送一条简短消息。两边都能正常响应后，再继续注册或开展任务。

如果连接不稳定，先检查订阅是否过期、节点是否可用，以及是否同时运行了多个互相冲突的代理工具。网络连通也不等于账号自动获得所有服务权限。

## 03 · 下载并安装

### 从官方入口获取客户端

打开 [OpenAI 快速开始页面](https://learn.chatgpt.com/docs/quickstart)，在桌面端安装部分选择与你的系统匹配的下载入口。当前官方教程以 **ChatGPT 桌面应用中的 Codex** 为入口，因此下载页面显示 ChatGPT 名称是正常的。

Windows 用户按官方页面引导完成安装；如果进入 Microsoft Store，请核对发布者为 OpenAI。macOS 用户下载后，按安装窗口的提示完成操作。具体系统要求和安装方式，以下载页面的当前说明为准。

![原教程中的 Windows 下载画面：Microsoft Store 显示 ChatGPT，发布者为 OpenAI](./images/codex-getting-started/install.png)

*图 1：原教程中的 Windows 下载示例。安装包大小和下载进度仅为当时画面。*

### 安装前准备好这些东西

- 可以正常访问官方服务的网络环境。
- 用于登录的个人账号，以及能够接收验证信息的邮箱。
- 一个空的练习文件夹，稍后用于保存第一个任务的文件。

先完成客户端安装即可，不必为了跟上这篇教程，同时安装命令行工具、第三方助手或一整套开发环境。

## 04 · 注册账号并登录

打开应用，点击“继续登录”或类似按钮，在浏览器里完成登录，再返回客户端。没有账号时，按官方注册页面的提示创建账号；如果页面要求进一步验证，就按当前页面的要求完成。不要把某次注册流程当成所有账号固定不变的步骤。

![原教程中的登录界面，红框标出了“继续登录”按钮](./images/codex-getting-started/login.png)

*图 2：通过“继续登录”进入账号登录流程。*

### 没有账号：先完成注册和邮箱验证

1. 在登录页面选择“注册”；已有账号则直接登录。
2. 按页面提示填写自己的邮箱，或选择页面提供的 Google、Apple、Microsoft 等登录方式。
3. 如需设置密码，按页面的当前要求填写；如采用一次性验证码方式，则进入邮箱查收验证码。
4. 回到注册页面，填写邮箱验证码并继续，完成页面要求的其他资料。
5. 注册完成后返回客户端，继续账号授权和登录流程。

![注册入口与邮箱、第三方账号登录选项](./images/codex-getting-started/register.png)

*注册页面示例：有账号时使用原来的登录方式，没有账号时选择“注册”。*

没有收到邮件时，先检查邮箱地址和垃圾邮件文件夹，再按页面提示重新发送。验证码只填写在对应的官方验证页面。

本文采用 ChatGPT 账号登录路线。API key 是另一种认证方式，使用量按 API 规则计费，并不等同于 ChatGPT 订阅额度；初次练习无须先配置它。登录方式及差异见 [OpenAI 身份验证说明](https://learn.chatgpt.com/docs/auth)。

## 05 · 遇到手机号验证：号码与接码流程

**只有实际出现手机号验证页面时，才需要处理这一节。** 不要把“所有新账号都需要海外手机号”当成固定规则；页面未要求时直接继续登录。

![手机号验证页面示例，需要选择国家代码并填写电话号码](./images/codex-getting-started/phone.png)

优先使用自己能长期控制、且符合页面要求的号码。接码平台提供的是临时号码，可能被目标服务拒绝，后续再次验证时也可能无法取回同一号码。因此，接到一次验证码不代表账号今后能够稳定登录或找回。

### 接码操作：以 HeroSMS 为例

下面保留教程中的 [HeroSMS](https://hero-sms.com/cn) 操作路线。该平台是第三方服务，号码价格、库存和能否通过目标服务验证均会变化，不保证“三分钟完成”或一次成功。

**第一步：注册并充值。** 打开平台，注册并登录账户，进入充值页面。先查看当前可用支付方式、最低充值额和手续费，再决定充值。教程画面曾展示支付宝与微信支付，但当前支持情况以结算页面为准。

**第二步：选择接收短信和服务。** 进入“接收短信”，在服务搜索框中输入 `OpenAI`，选择匹配的服务。购买前确认该项目适用于你正在进行的验证流程。

![HeroSMS 服务选择示例，在搜索框输入 OpenAI](./images/codex-getting-started/sms-service.png)

**第三步：选择国家和号码时长。** 根据平台当前库存与目标页面的号码要求选择国家，再检查接收时长、单价和未收到验证码时的处理规则。不要将某个国家在教程中成功过，理解为当前一定可用。

![号码购买页面示例，显示 20 分钟时长及当时的价格](./images/codex-getting-started/sms-order.png)

*截图中的 20 分钟、0.33 美元及退款提示是当时页面的示例，实际订单以购买时显示的条款为准。*

**第四步：填写购买到的号码。** 获得号码后，返回官方验证页，选择对应国家代码并填写号码。核对国家代码是否已经由页面自动添加，避免重复输入，然后请求发送验证码。

**第五步：接收并填写验证码。** 回到接码订单页面等待短信，必要时刷新订单状态。收到后，将本次验证码填写到对应的官方验证页面，继续完成验证。

**第六步：检查结果。** 官方页面显示验证完成后，再返回客户端继续登录。如果号码被拒绝或一直收不到短信，按订单当前规则处理取消或退款；不要把付款成功当成验证已经成功。

验证码和完整电话号码无需写入学习笔记。保留服务名称、操作步骤和错误信息，便于以后排查即可。

## 06 · 进入 Codex，发起第一次对话

登录后，从应用的模式菜单中选择 **Codex**。如果入口或按钮与截图不同，先对照当前版本的 [官方快速开始](https://learn.chatgpt.com/docs/quickstart)。账号可用功能和额度，以实际账号页面为准。

可以先发送一条简单的问题，熟悉输入和回复区域：

```text
我是第一次使用 Codex。请用中文说明，我怎样创建一个本地练习项目，
以及完成任务后应该到哪里查看生成的文件。
```

## 07 · 准备一个练习项目

在电脑上新建空文件夹，例如 `codex-first-project`，再在客户端中通过创建项目或打开文件夹的入口选中它。

可以这样理解接下来要用的两个概念：

- **项目**：组织这次工作的文件和上下文。
- **任务或对话**：围绕一个具体目标，与 Codex 交流和修改结果的过程。

第一次练习使用空目录，方便看清它新增了哪些文件。文件访问与命令执行范围由实际权限设置决定，不能仅凭“选择了项目”就认为其他目录一定不可访问。同一目录里的多个任务也可能修改同一份文件，因此这次先只做一个任务。

## 08 · 第一个任务：制作学习记录页面

原教程的基础使用部分展示了制作 3D 帆船小游戏的案例。为了让第一次练习更容易检查结果，这里另写了一个更小的练习：制作一页学习记录。下面的提示词是本文补充的示例。

在练习项目中新建任务，复制这段需求：

```text
请在当前练习文件夹中制作一个“我的学习记录”网页。

要求：
1. 使用一个 index.html 文件，样式和脚本都写在其中，不依赖外部服务。
2. 页面包含标题、一句介绍，以及三张学习笔记卡片。
3. 卡片内容使用明确标注的示例文字，不要编造我的个人经历。
4. 使用粗黑边框、硬阴影和黄紫青配色，正文保持清晰易读。
5. 手机和电脑上都能正常阅读。
6. 只在当前练习文件夹新增文件，不上传或发布网站。

完成后请说明生成了什么、如何在本地打开，以及你实际检查过哪些内容。
```

这段需求交代了四件事：**做什么、长什么样、保存在哪里、怎样算完成。** 比起只说“帮我做一个网页”，它更容易得到可以检查的结果。

执行过程中，如果出现操作许可提示，先看清它准备运行什么命令、访问什么位置，再决定是否允许。这里练习的是本地网页，收到要求上传内容或修改账号设置的建议时，可以让它先解释必要性。

## 09 · 打开结果，再做一次修改

任务完成后，按照回复中的文件路径找到 `index.html`，用浏览器打开。不要只看“已完成”三个字，实际检查页面是否符合自己的需求：

1. 标题、介绍和三张笔记卡片是否齐全。
2. 中文有没有乱码，颜色和字号是否容易阅读。
3. 缩窄浏览器窗口后，内容有没有被挤出屏幕。
4. 练习文件夹中是否只出现了这次需要的文件。

如果需要调整，就在同一任务里继续描述具体问题，例如：

```text
保留当前的配色、粗黑边框和硬阴影。
请把正文调大一些，让手机上的卡片上下排列，
并把页面介绍改成“把每天学到的东西，留下一页记录”。
修改后告诉我具体改了哪些地方。
```

一次修改一组相关问题，更容易判断效果。遇到错误时，提供报错文字、对应文件名或截图，比只说“运行不了”更有帮助。

完成这一步，就走通了一次完整的协作过程：提出目标、生成文件、查看结果、反馈修改。之后可以再尝试整理 Markdown 笔记、制作个人页面，或给已有的小项目增加功能。

## 10 · 遇到问题时，先分清卡在哪一步

| 现象 | 建议先检查 |
| --- | --- |
| 官方下载页打不开或下载中断 | 网络连接和下载入口是否正常，是否拿到了对应系统的安装包 |
| 浏览器登录完成，客户端仍未登录 | 返回应用重试登录，并核对当前账号；仍失败时保留错误信息 |
| 看不到预期的 Codex 入口 | 应用版本、当前模式以及账号实际可用功能 |
| 出现 Reconnecting | 记录发生时间和错误提示，检查网络；不要直接认定是模型正在思考 |
| 页面生成了，但效果不对 | 打开实际文件，用具体描述或截图指出需要调整的位置 |

关于反复重连，可以继续阅读本站的 [Codex 重连问题处理记录](https://caodongbiaogggg.github.io/shiye/#codex-reconnecting-system-proxy)。其中的配置方法有适用范围，不能保证解决所有连接问题。
